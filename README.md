# Predicting Traffic Emissions in Sydney using Machine Learning and Explainable AI

## Project Overview
This project investigates the use of machine learning models to predict traffic-related CO2 emissions in Sydney and applies Explainable AI techniques to identify key factors influencing predictions.

## Objectives
- Evaluate machine learning approaches for traffic emission prediction
- Investigate the impact of traffic, environmental and temporal features
- Apply XAI techniques to improve model interpretability

## Methodology
1. Data collection
2. Data preprocessing
3. Feature engineering
4. Model development
5. Model evaluation
6. Explainable AI analysis
